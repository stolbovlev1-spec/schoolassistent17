# Школьный Помощник — PWA

Готовый статический PWA для GitHub Pages.

## Возможности

- Домашние задания с датой и отметкой выполнения.
- Оценки по предметам и средний балл.
- Правило четвертной оценки: `3.49 → 3`, `3.50 → 4`, `4.49 → 4`, `4.50 → 5`.
- Расчёт цели на четверть.
- Профиль с классом.
- Тёмная/светлая/авто тема и цвета.
- Gemini API для распознавания расписания с фотографии.
- API ключ вводится самим пользователем и сохраняется только локально.

## Запуск

Можно открыть `index.html` через локальный сервер или разместить репозиторий на GitHub Pages.

Для GitHub Pages:
1. Создай репозиторий.
2. Загрузи все файлы из этой папки.
3. Settings → Pages.
4. Source: GitHub Actions или Deploy from branch → `main` / root.
5. Открой получившийся адрес.

## Gemini

В приложении: Настройки → Gemini API ключ.

Класс из профиля автоматически подставляется в промпт:
`Найди именно колонку класса "10А"...`

При изменении класса, например на `9Б`, запрос автоматически использует `9Б`.

По умолчанию стоит `gemini-2.5-flash`; поле модели можно поменять вручную. Если у твоего API доступна другая модель, укажи её там.

### Важное замечание по API-ключу

Ключ не лежит в GitHub-репозитории и не является общим для всех пользователей. Но любой секрет, используемый непосредственно из браузера, в абсолютном смысле не является скрытым: пользователь может увидеть свои сетевые запросы. Для личного PWA это приемлемый компромисс; для публичного сервиса с большим количеством пользователей лучше добавить серверный proxy и ограничения API key.

## Архитектура

Сейчас это vanilla HTML/CSS/JS без сборщика, чтобы проект было максимально легко залить на GitHub Pages. Позже можно без проблем перенести логику в React/TypeScript.
